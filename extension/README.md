# FocusLens browser extension

Optional, separate from the Windows application. In Chrome or Edge, open the Extensions page, enable Developer mode, choose **Load unpacked**, and select this directory. Pin FocusLens, enter domains, and turn blocking on or off. Rules work locally and no browsing history is transmitted or saved.

The extension blocks top-level navigation to configured domains and subdomains through Manifest V3 declarative rules. It does not inspect page content. Because the desktop app cannot observe another browser's tabs, desktop blocklist entries are reminders and do not automatically synchronize with this extension. Turn off the extension's blocking when your session ends. No automatic desktop integration is claimed.
