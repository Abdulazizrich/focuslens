# Vision integration fixture

`astronaut.png` is the NASA portrait of Eileen Collins distributed as
`skimage.data.astronaut`. It is used only in automated face-presence tests and is
not shipped in the FocusLens installer. No identity recognition is performed.

The scikit-image documentation identifies this photograph as public domain, with
no known copyright restrictions:
https://scikit-image.org/docs/stable/api/skimage.data#skimage.data.astronaut

Downloaded from the pinned scikit-image v0.25.2 source:
https://raw.githubusercontent.com/scikit-image/scikit-image/v0.25.2/skimage/data/astronaut.png

Original source credited by scikit-image: NASA Great Images database,
https://flic.kr/p/r9qvLn
